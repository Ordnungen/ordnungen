## What I do

<p>
  <a href="https://www.linkedin.com/in/ordnung"><img src="https://img.shields.io/badge/LinkedIn-ordnung-0A66C2?style=flat-square&logo=linkedin&logoColor=white" alt="LinkedIn"></a>

- **Requirements.** Intake, analysis and agreement with the customer: turning a request into a task with acceptance criteria.
- **Integrations.** Interface design and contracts: what systems exchange, in what format, and what happens when a step fails.
- **Specifications.** Technical statements for developers, interface models, data schemes, user guides.
- **Data.** SQL and stored procedures, query tracing and optimisation, ETL pipelines, exploratory analysis.
- **AI and LLM.** Prompt engineering and automation of routine operations.
